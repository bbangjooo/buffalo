# 여백을 남긴 앤틱 펜드로잉 아틀라스

## 확정된 디자인

사용자가 제공한 지도·문장 그림 1–3의 밝은 종이와 브라운 잉크,
그림 4의 검은 바탕과 밝은 선을 기준으로 한다. 이전의 넓은 중세 마을과
푸른색·주황색 야경 설계는 이 방향으로 대체한다.

핵심은 **중앙 네 공간이 주인공이고, 주변으로 마을과 정원이 이어지는 것**이다.
중앙의 크기와 위계가 확보된 뒤에는 마을의 범위와 물체 수를 늘렸다.
가까운 생활 소품과 더 먼 집·정원 사이에 여백을 두어 공간의 깊이를 만든다.

- 낮: 종이 `#eadcc0`, 물체의 밝은 면 `#f2e6ce`, 잉크 `#5c422d`.
  미세한 종이 결만 넣고 과한 얼룩·그을린 테두리를 사용하지 않는다.
- 배경: 작은 집 다섯 채와 우물·가판대·수레·게시판·나무통·상자 군집,
  총 11개 마을 요소를 배치한다. 가까운 정원과 외곽 정원은 총 13곳이다.
  풀 146개·꽃 31개·관목 19개·나무 12그루·돌 12개, 총 220개 식재를
  군집으로 두며 앞쪽 통로와 중앙 집 주변은 비워둔다. 화면 전체에 식생을 반복하지 않는다.
  식재가 차지하는 외곽 범위는 약 27.2×30.6m에서 50.7×48.4m로 넓혔다.
- 중심 구도: 시점을 조금 낮추고 카메라 구도를 가까이 조정한다.
  검증한 화면에서 주요 물체의 가로 크기는 16–17%, 화면상 면적은 31–41% 커졌다.
  문서·사진·오르간 상단은 잘리지 않도록 유지한다.
- 배경 위계: 첫 화면에서 작은 집 하나와 나무 두 그루가 확실히 보이되,
  집은 작은 배율, 식물은 옅은 선으로 중앙 네 방보다 약하게 표현한다.
  추가 건물은 바깥 골목에 분산하고 수레·나무통·상자는 가까운 생활 소품으로 둔다.
  외곽 확장에서도 중앙 방의 카메라, 오브젝트 크기, 콘텐츠는 바꾸지 않는다.
- 중앙: 바닥의 반복 격자와 벽의 잔선을 줄이고, 악기·게시판·책상·책·커튼에
  윤곽·문양·재질·선택적 해칭을 집중한다.
- 악기: 21개 파이프와 조각 케이스를 갖춘 소형 실내 오르간.
  기존 24개 건반, 악보, 좌석, 입력과 연주 콘텐츠는 보존한다.
- 현대적 외형: 모니터 케이스는 조각 게시판, 회전 의자는 목제 의자,
  책상 주변은 필기 도구로 바꾼다. 게임은 난간 없는 조각 보드로 표현한다.
- 밤: `#050607` 바탕, 은회색·아이보리 선과 별. 넓은 남색·주황색 면을 없애고
  횃불의 밝기는 가까운 작은 부분에만 남긴다.
- 로봇·햄스터의 모델과 고유 재질은 그대로 유지한다.

## 나침반과 콘텐츠 접근

우측 하단의 네 방향 나침반은 방 선택기다. 방별 기존 회전 순서를 사용하며,
현재 방을 표시한다. 실제 지리 방향이나 GPS를 나타내는 기능은 아니다.
마우스 hover와 키보드 focus에서 각 방 이름을 확인할 수 있다.

모바일에서는 나침반이 기존 이전/다음 버튼을 대체한다. 왼쪽에는 기존 행동
버튼을 두어 중앙 방 모델을 가리지 않는다. 글 읽기·게임·좌석·야외 이동 중에는
해당 콘텐츠의 조작을 우선하여 나침반을 숨긴다.

기존 야외 기록 전시는 `Explore`로 들어갔을 때만 나타난다. 기록이나 글을
삭제하지 않고 초기 화면의 장치 밀도만 낮춘다. 실내 확대 읽기에서는
배경 랜드마크를 숨기고, 일반 방 화면으로 돌아오면 복원한다.

## 버튼 여백과 화면 전환

제목은 상하 8px·좌우 12px, 프로필 링크는 상하 10px·좌우 10–12px의
실제 안쪽 여백을 갖는다. 링크 사이에는 6px을 남기며, 종이색 바깥 그림자로
여백을 흉내 내던 표현은 가벼운 반투명 바탕과 작은 그림자로 바꾼다.

낮·밤의 글자·버튼 면·테두리·나침반 선·보조 문구는 장면과 같은 1.1초
전환을 사용한다. 해/달 아이콘도 교차해서 나타난다. 방 이동 중에는 하단
조작부가 55% 밝기로 잦아들고 이동 완료 후 복원되며, 새 행동 버튼은 짧게
나타난다. 오르간 건반·이동 키·리듬 입력과 판정에는 전환 지연을 넣지 않는다.
`prefers-reduced-motion`에서는 전환과 등장 애니메이션을 끈다.

1440×960, 390×844, 320×740에서 제목·상단 버튼·링크·나침반 배치를 확인했다.
낮·밤을 바꿔도 제목과 링크의 위치·크기는 유지된다. 방 선택·좌석 진입과 복귀·
키보드 펼치기·정보 메뉴를 실제 브라우저에서 확인했으며 콘솔 오류는 없었다.
검토 화면은 `assets/ui-comfort-day.png`, `assets/ui-comfort-night.png`에 저장한다.

## 로컬 구현과 재현

- 브랜치/워크트리: `codex/pen-ink-world`, `/Users/bbangjo/buffalo-pen-ink`.
- 로컬: `http://localhost:4178/`.
- `scripts/build_pen_ink_rooms.py`: 오르간·가구·커튼과 상세 펜선.
- `scripts/pen_ink/room_atlas_organ.py`, `room_atlas_furniture.py`: 핵심 물체 외형.
- `scripts/build_medieval_village.py`: 분산된 마을의 11개 배경 요소 생성.
- `src/design/atlas-landscape.json`: 220개 식재의 위치·크기·여백 계약.
- `Meadow.ts`: 단일 종이 평면과 고정 식재 5개 배치. 이동할 때는 바닥만 따라온다.
- `PenInk.ts`: 중립 GLB의 흰 면/잉크를 종이·갈색 잉크·흑백 야경으로 표현.
- `AtlasCompass.tsx`/CSS: 기존 이동 이벤트를 사용하는 SVG 나침반.
- `assets/atlas-world.blend`: Day/Night 통합 Blender 검토 파일.
  기본 `VillageOverviewCamera`는 확장한 마을 전체를 보여주며,
  `RoomCompositionCamera`에는 기존의 가까운 방 구도를 보관한다.
- 이전 결과 백업: `assets/archive/atlas-before/`.

## 확인 항목

- `verify-pen-ink.cjs`: 원본 캐릭터·앵커·24개 건반과 좌석 시야, 중립 GLB 계약.
- `verify-medieval-village.cjs`: 현재는 Atlas 검증을 수행한다. 선언된 배경 요소,
  고정 식재·여백·원본 보존, 이동/충돌, 밤 전환/복원/모션 감소, 나침반 이동 등을 검사한다.
- `verify-atlas-framing.cjs`: 변경 전 카메라와 실제 오브젝트 투영을 비교하여
  확대 정도·화면 여백·이동/읽기 복귀를 검증한다.
- 기존 연주·오디오·리듬게임·이동·커튼·카메라·리더보드 회귀 검사.
- 실제 390×844 화면에서 나침반과 행동 버튼이 겹치지 않으며,
  나침반으로 네 방 이동과 현재 방 표시가 갱신된다. 가로 넘침 없음.
- 소개와 기록 문서는 원래 내용을 유지하고 낮/밤 읽기 색상만 바뀐다.

Blender의 장면은 편집·정적 조명 검토용이며, 실제 HTML 콘텐츠와 입력,
연주·애니메이션은 로컬 블로그에서 확인한다.
`assets/*.png`와 `assets/archive/`는 로컬 검토 산출물이다. PR용 화면은
`docs/media/atlas/`에 보관한다.
